# Homework drafts for a future cohort

Homework for modules 6 (Best Practices) and 7 (Project Example). The 2026
cohort ran without homework for these modules, so they are not part of
`cohorts/2026/`.

To use one in a cohort, move its directory to
`cohorts/<year>/homework/<module>/`, set `due_at`, and list it under
`homework:` in that cohort's `cohort.yaml`. The encrypted answers are bound to
the course, the homework `slug` and the question `id`, so keep those as they
are or re-encrypt the answers.
